# Network

I document the networking side of ITLLERY here: the reasons behind the design, what I have configured, how I tested it and what still needs work.

- [01 — Network architecture](01-architecture.md) — roles, segmentation principles, implemented controls and pending tests.
- [02 — Physical components and topology overview](02-physical-topology.md) — public-safe equipment layout and deployment status, **not** live cabling.

The public diagrams are intentionally sanitized. Real VLAN identifiers, addressing, port assignments, management paths, complete router exports and backups stay in private documentation. A diagram or a planned service is not proof that a control has been deployed or tested.

**Latest review:** 2026-11-21.
