# Backups and recovery

I use a dedicated Proxmox Backup Server on demand rather than keeping it running all the time. The [hardware inventory](../../docs/hardware/hardware-inventory.md) has its public specifications.

I also keep notes about router recovery and a possible second backup location. Creating a backup and proving that I can restore it are different tasks, so I plan to document a restore test separately. The [network recovery notes](../../runbooks/network-recovery.md) cover that distinction.
