# Proxmox hosts

I have two Proxmox systems: a SOC Core and a separate Service host. I use them to keep security workloads apart from other services.

Both management web interfaces were reachable after the November network recovery. That was an access check, not a full review of every VM or hypervisor setting. I'll add more detailed setup notes and tested changes as I work through them.

The [hardware inventory](../../docs/hardware/hardware-inventory.md) lists the public host specifications.
