# Public sharing rules

I share architecture concepts, generic examples, sanitized evidence, tested defensive rules, lessons and remediation steps.

I don't publish passwords, tokens, WireGuard private keys, real management paths, complete firewall exports, backup recovery secrets, unreviewed packet captures or malware binaries.

Every screenshot and log needs a manual check before publishing. Removing a secret from a file doesn't undo its exposure in Git history: rotate it if that ever happens.
